Yawmiyati Android project — v1.0.1

Open the Yawmiyati_Android_v36 folder in Android Studio.
Use a JDK/Android Gradle Plugin compatible with the project.
Then: Build > Generate App Bundles or APKs > Generate APKs.
The app loads the bundled web app from app/src/main/assets/index.html.
The branded logo is bundled at app/src/main/assets/assets/yawmiyati_logo.png and used by the About screen.
